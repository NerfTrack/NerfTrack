## What's new in NerfTrack v1.1.8

- Weekly estimates now wait for missing prices, use matched quota coverage for confidence, and recognize weekly resets even when the first new reading is higher.
- Fixed several ways older, repeated, or quota-only log records could distort usage totals. The app separates accounts when the logs identify them.
- Existing estimates are recalculated after upgrade. NerfTrack corrects older token counts where the original logs are still readable and retains saved usage from unavailable logs.
- Reimports retain the existing index when the source scan fails. Reset boundaries and offline prices are preserved during later rebuilds.
- Fixed model ID editing, chart range changes during refresh, and GitHub update checks. Release notes appear at startup and are available in Settings.
